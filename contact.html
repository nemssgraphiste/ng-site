1. Responsable du traitement

Le responsable du traitement des données est le propriétaire du site NG Creative.

Contact : contact@ngcreative.fr

2. Données collectées

Selon votre utilisation du site, les données suivantes peuvent être collectées :

Formulaire de contact

Lorsque vous utilisez le formulaire de contact, les informations suivantes peuvent être demandées :

  • Nom
  • Adresse e-mail
  • Objet de la demande
  • Contenu du message

Ces informations sont fournies volontairement par l'utilisateur.

Données techniques

Lors de votre navigation, certaines informations techniques peuvent être enregistrées automatiquement par votre navigateur ou votre hébergeur, notamment :

  • Adresse IP

  • Système d'exploitation

Ces données sont utilisées uniquement pour assurer le bon fonctionnement, la sécurité et la maintenance du site.

3. Finalité des données

Les données collectées sont utilisées uniquement afin de :

  • répondre à vos demandes de contact ;
  • échanger avec vous dans le cadre d'un projet ou d'une demande d'information ;

  • prévenir les tentatives de fraude ou d'utilisation abusive.

Aucune donnée personnelle n'est vendue, louée ou transmise à des fins commerciales.

4. Base légale du traitement

Les traitements réalisés reposent sur :

  • votre consentement lorsque vous remplissez volontairement un formulaire de contact ;

Les données sont conservées uniquement pendant la durée nécessaire à leur traitement.
